⚡ GreeceEVForecast

Forecasting EV charging demand and electricity trends in Greece to support smarter, cheaper, and greener electric vehicle usage.

📊 Overview

GreeceEVForecast is a time-series forecasting project focused on predicting electricity demand and/or EV charging patterns in Greece. The goal is to help EV owners, energy analysts, and smart charging systems make better decisions based on expected energy availability and cost.

This project can be used for:

🔋 Optimizing EV charging schedules
💰 Reducing electricity costs
🌍 Improving renewable energy usage alignment
📈 Analyzing energy consumption trends in Greece

⚙️ Features
 - Time-series forecasting of EV-related electricity demand
 - Greece-focused energy context
 - Extensible forecasting pipeline (ML/statistical models)
 - Data preprocessing and feature engineering
 - Visualization of predictions and trends
 - API-ready structure (optional, if you add FastAPI later)
